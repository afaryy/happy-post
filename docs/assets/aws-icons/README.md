# AWS Architecture Icon Assets

The SVG files in this directory are unmodified service icons selected from AWS’s official Architecture Icons package, downloaded on 29 July 2026 for the Happy Post documentation diagram.

Source: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/). AWS publishes updated packages quarterly; use the official source to refresh icons rather than editing these assets.

The icons are retained for AWS architecture documentation. The current focused diagrams are [the runtime architecture](../../diagrams/aws-ecs-runtime-architecture.drawio.svg) and [the delivery/control-plane architecture](../../diagrams/delivery-and-control-plane.drawio.svg).
